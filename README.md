# Zarabatalo!

Это учебный пет-проект, представляющий собой игру, аналог существовавшей ранее русской игры "Заработало!".

## Цель проекта:
Подготовка к собеседованию на позицию Senior Frontend Developer, с акцентом на следующие технологии и концепции:

- **React**
- **Next.js** (Page Router, App Router)
- **TypeScript**
- **React.memo, useMemo, useCallback** (мемоизация)
- **Кастомные хуки** (usePrevious, useDebounce, useThrottle)
- **Управление состоянием** (useState, useRef, useContext, Zustand)
- **ESLint и Prettier** (для поддержания качества кода и стиля)
- **Клиент-серверное взаимодействие, асинхронные запросы**
- **GraphQL, Apollo Client (кэширование и нормализация данных) или аналогичные инструменты (TanStack Query)**
- **UI-библиотеки и стилизация** (Ant Design, Styled-components)
- **Работа с датами** (Day.js)
- **Интернационализация** (Next-intl)
- **Базовое знание Nest.js** (для работы с файлами)
- **Event Loop и понимание клиент-серверного взаимодействия**
- **Observer API** (Intersection Observer, Resize Observer и др.)
- **Кэширование, нормализация данных и эффективное управление запросами** (Polling, Refetch, Lazy, Queries/Mutations)
- **Оптимизация загрузки изображений и работа с виртуализацией**
- **Понимание Property Drilling и правильное использование контекста**

## Текущий прогресс:
- Проект инициализирован с Next.js и TypeScript.
- Настроены ESLint и Prettier для автоматического форматирования и проверки кода.
- Структура проекта приведена в соответствие с рекомендациями Next.js.
- Инициализирован Git репозиторий, первый коммит сделан в ветку `dev`.

## Задачи:
Задачи для самостоятельной работы находятся в папке `tasks/`.
