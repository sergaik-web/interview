# Проект "n8n-like"

Это мой учебный пет-проект, который представляет собой упрощенную версию популярной программы для автоматизации рабочих процессов — n8n.

## Цель проекта:
Подготовка к собеседованию на позицию Senior Frontend Developer. Проект сфокусирован на глубоком изучении и практическом применении технологий, указанных в требованиях к вакансии:

- **React** и **Next.js** (Page Router, App Router)
- **TypeScript**
- **Оптимизация рендеринга**: `React.memo`, `useMemo`, `useCallback`
- **Кастомные хуки**: `usePrevious`, `useDebounce`, `useThrottle`
- **Управление состоянием**: `useState`, `useRef`, `useContext`, `Zustand` (для SignalR)
- **Клиент-серверное взаимодействие**, асинхронные запросы
- **Работа с данными**: `GraphQL`, `Apollo Client` (кэширование и нормализация данных) или `TanStack Query`
- **UI-библиотеки и стилизация**: `Ant Design` (кастомизация и стилизация), `Styled-components`
- **Работа с датами**: `Day.js`
- **Интернационализация**: `Next-intl`
- **Базовое знание Nest.js** (для работы с файлами)
- **Event Loop** и понимание клиент-серверного взаимодействия
- **Observer API**: `Intersection Observer`, `Resize Observer` и др.
- **Кэширование**, нормализация данных и эффективное управление запросами (Polling, Refetch, Lazy, Queries/Mutations)
- **Оптимизация загрузки изображений** и работа с виртуализацией
- **Понимание Property Drilling** и правильное использование контекста
- **ESLint** и **Prettier** (для поддержания качества кода и стиля)

## Текущий прогресс:
- Проект инициализирован с Next.js и TypeScript.
- Настроены ESLint и Prettier для автоматического форматирования и проверки кода.
- Структура проекта приведена в соответствие с рекомендациями Next.js.
- Инициализирован Git репозиторий.

## Задачи:
Задачи для самостоятельной работы и изучения технологий находятся в папке `tasks/`.
