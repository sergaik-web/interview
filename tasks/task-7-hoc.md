# Урок 7: Higher-Order Components (HOC)

## Что такое HOC?

**Higher-Order Component (HOC)** — это продвинутый паттерн в React для повторного использования логики. HOC — это функция, которая принимает компонент и возвращает новый компонент с расширенным функционалом.

Проще говоря: `const EnhancedComponent = higherOrderComponent(WrappedComponent);`

HOC позволяют:

- Повторно использовать логику.
- Абстрагировать и ма-нипулировать состоянием (state).
- Манипулировать пропсами (props).
- Не изменять исходный компонент.

Хотя хуки (Hooks) стали основным способом для повторного использования логики, понимание HOC всё ещё важно, так как они часто встречаются в существующих кодовых базах и библиотеках.

## Задание:

Твоя задача — создать HOC `withSimpleLogger`, который будет логировать в консоль пропсы компонента при каждом его рендере.

### Шаг 1: Реализуй HOC

- Открой файл `src/components/withSimpleLogger.tsx`.
- Внутри него тебе нужно реализовать логику HOC.
- HOC должен принимать компонент (`WrappedComponent`) в качестве аргумента.
- Внутри HOC создай новый функциональный компонент, который будет использовать хук `useEffect` для вывода в консоль всех пропсов (`props`), которые он получает.
- HOC должен возвращать этот новый компонент.

### Шаг 2: Примени HOC к компоненту

- Открой файл `src/components/EnhancedDisplayData.tsx`.
- Импортируй `DisplayData` и твой HOC `withSimpleLogger`.
- Создай новый компонент `EnhancedDisplayData`, применив HOC к `DisplayData`.
- Экспортируй `EnhancedDisplayData` по умолчанию.

### Шаг 3: Отобрази результат

- Открой `pages/index.tsx`.
- Импортируй `EnhancedDisplayData`.
- Вставь его в рендер, передав какие-нибудь пропсы, например:
  `<EnhancedDisplayData title="HOC Demo" data="This component is wrapped with a logger." />`
- Запусти приложение (`npm run dev`) и открой консоль в инструментах разработчика в браузере. Ты должен увидеть логи пропсов от твоего HOC.
